## 5. 一致性对比与差异分析

### 5.1 唯一差异项及其定性（预期差异，非缺陷）

| 差异项 | 账本 | A 端值 | B 端值 | 定性 |
|---|---|---|---|---|
| `is_shared, member_count` | 家庭共用账本（`c9643738-…`） | `(1, 2)` | `(0, 1)` | **预期差异** |

**原因分析**

1. `is_shared` / `member_count` 描述的是「**本机视角**的共享开启状态与成员数」，属设备/账号本地状态，不是业务数据；
2. 账本成员关系表 `ledger_members` 是账号-设备维度的授权记录，**不参与云端快照**（快照 JSON v9 的账本元数据块仅含 `version / exportedAt / ledgerId / ledgerName / currency / ledgerSyncId / monthStartDay / count`）；
3. A 端注入脚本显式设置 `is_shared=1, member_count=2`（模拟「已邀请 1 名成员」），B 端首次导入按默认值落库 `(0, 1)`；
4. 该字段**不在同步字段清单**内（清单为 `name / currency / type / month_start_day / my_role`），比对脚本单列 `[OK*]`，不计入 issues、不影响退出码（exit=0）。

**结论**：设计边界内的预期行为，不构成同步缺陷。与本日 S3 轮及历史 7 轮表现**完全同构**。

### 5.2 已排查并确认「非问题」的现象

| # | 现象 | 排查结论 |
|---|---|---|
| 1 | WebDAV 轮 A 端**没有**「附件对象上传完成」日志（S3 轮有） | **内容寻址去重命中，属正确行为**。服务端 `attachments/` 已存在 7 个同名（= 明文 sha256）对象，A 端日志显示 `附件目录列举走会话缓存(7 项)` ×7，判定「云端已存在 → 跳过」；服务端附件目录 mtime 保持 `2026-09-16 22:14` 未变、对象字节零改动。S3 轮为空桶起步，故必须实际上传。 |
| 2 | 服务端密文对象 sha256 与文件名（明文 sha256）不相等 | **并非错误**。文件名是**明文**内容寻址键；E2EE 开启时服务端落盘为 `BEECRYPT1:` 密文 + gzip 外层信封，故密文 sha256 必然不同。B 端解密落盘后 sha256 与文件名 7/7 一致，证明往返无损。 |
| 3 | 服务端槽位 JSON 体积由 ≈ 2.44 MB 降到 ≈ 0.53 MB | **并非数据丢失**。新写入为「E2EE 密文 + gzip 外层」；B 端下载解密后导入 5001/5001 条、逐字段与 A 端一致，证明体积变化只是压缩/加密形态差异。 |
| 4 | WebDAV 每账本上传 1.70 ~ 2.55 s，明显慢于 S3 的 0.82 ~ 2.00 s | **协议开销差异，非缺陷**。WebDAV 上传每账本额外产生 OPTIONS / MKCOL / PUT(.tmp) / MOVE / PROPFIND / GET 的多次往返（服务端日志 66 PROPFIND + 63 OPTIONS + 55 GET）；S3 走单次 PUT + 单次回读。属预期。 |
| 5 | 切换后端瞬间出现 `SyncDiff.error → noRemote/localNewer` 等瞬态 | 切换后首个探测周期远端上下文尚未建立，下一周期即稳定，非稳定性问题。 |
