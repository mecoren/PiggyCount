## 5. 一致性对比与问题分析

### 5.1 唯一差异项及其定性（预期差异，非缺陷）

| 差异项 | 账本 | A 端值 | B 端值 | 定性 |
|---|---|---|---|---|
| `is_shared, member_count` | 家庭共用账本（`0c68a6be-…`） | `(1, 2)` | `(0, 1)` | **预期差异** |

**原因分析**

1. `ledgers.is_shared` / `member_count` 的语义是「**本机视角**下该账本的共享开启状态与成员数」，属设备/账号本地状态，不是业务数据；
2. 账本成员关系表 `ledger_members` 是账号-设备维度的授权记录，**不参与云端快照**（快照 JSON v9 的账本元数据块仅含 `version/exportedAt/ledgerId/ledgerName/currency/ledgerSyncId/monthStartDay/count`）；
3. A 端注入脚本显式设置 `is_shared=1, member_count=2`（模拟「已邀请 1 名成员」的本机状态），B 端首次导入按默认值落库 `(0, 1)`；
4. 该字段**不在同步字段清单**内（清单为 `name / currency / type / month_start_day / my_role`），比对脚本将其单列 `[OK*]`，不计入 issues、不影响退出码。

**结论**：设计边界内的预期行为，不构成同步缺陷。
