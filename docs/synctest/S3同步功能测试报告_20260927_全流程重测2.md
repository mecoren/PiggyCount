## 8. 问题分析

**本轮未发现产品缺陷。** 两处过程记录：

1. **夹具误触（已复原，非产品问题）**：R1 首次点击「全量上传」时因页面布局偏移，坐标误触了「自动同步账本」开关（`flutter.auto_sync` false→true）；发现后立即经 UI 点回 false，并在 FSP 键级比对中确认与基线一致。教训已固化为 `sync_ui.py` 文本定位驱动（后续所有 UI 操作未再发生坐标漂移）。
2. **收敛模式（预期行为，非缺陷）**：合并方在更新周期规则后会本地物化 16 条新实例（40017→40033 / 40042→40058），需该方再上传一次才能收敛——这是周期记账的既定语义；且增量上传的冲突保护（"云端更新被跳过，请核对后逐个上传"）正确阻止了合并方在未合并状态下覆盖云端，收敛走「全量上传」路径，两轮均正常收敛。
