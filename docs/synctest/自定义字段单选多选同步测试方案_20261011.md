## 0. 本次新增行为（预期的依据）

以下即「本方案为什么这样断言」的来源，全部已在 `lib/` 落地：

1. **两个新类型**：`CustomFieldType.singleSelect` = 单选（值 = 单个字符串）；`CustomFieldType.multiSelect` = 多选（值 = 字符串列表，去重 + 字典序，空集合按缺失处理）。
2. **选项存储**：`custom_field_definitions.options_json`（可空 TEXT，JSON 字符串数组，顺序即展示顺序）；`NULL`/空数组 = 无选项。schema **v53 → v54**（纯新增、零回填，旧行导出逐字节不变）。
3. **选项改名级联**：改名一个已使用的选项 → 该账本交易 `custom_values_json`（单选替换串 / 多选替换列表项）与周期模板 `template_field_values` 同步改写，统计不裂桶。
4. **删除选项 ≠ 删值**：选项行从定义里移除后，历史值作为「游离值」保留（录入控件仍显示为选中态、可清除）。
5. **同步契约**：`customFields` 段每项**恒写 `options` 键**（含空数组）；指纹白名单 `customFieldCanon` 纳入 `options`；快照格式 **v12 → v13**；导入按**键存在语义**（缺键 = 旧快照 → 保留本地选项；显式空数组 = 云端权威 → 清空）。
6. **删除定义**：连带清理交易值与周期模板值；**全量下载**与**增量合并**均按 `syncId` 镜像删除（闸门：快照 version ≥ 8、本地有 syncId、无未推送 `local_changes`）。
7. **多选统计口径**：区间报表「自定义字段汇总」按**每个被选中的值分别归桶**（同一笔金额在多个桶重复计入）。
8. **已知边界**：CSV 导入的自动建字段仍只按值推断 amount/date/text，**不推断单选/多选**。

### 1.2 云配置（每个后端都遵守「配置保命绳」）

- **S3 轮**：A/B 均配置同一 S3 端点 / 区域 / AK / SK / 存储桶（个人中心 → 云服务 → S3 协议存储 → 测试连接）。
- **WebDAV 轮**：A/B 均配置同一 WebDAV URL / 账号 / 密码 / 远程路径（个人中心 → 云服务 → 自定义 WebDAV → 测试连接）。
- **两轮各自独立**：切换后端走「切换云服务」确认；切换前用 `scripts/live_db/run_*/cfg_backup.py` 备份并做**删前后 sha256 + 键值集合**比对（参考 `docs/test/S3同步功能测试报告_20261010.md` §8）。
- 同步加密（E2EE）：沿用既有同步密码，**不重设**（重设会改写 `flutter_secure_storage`，触碰云配置）。

### 1.3 测试数据准备（只在 A 端）

### 1.4 造数要求（关键：让两种新类型"铺满且形态多样"）

- 单选字段：≥ 4 个账本各 1 个定义，选项 ≥ 3 个（含中文、空格、标点、`=`、引号）。
- 多选字段：≥ 4 个账本各 1 个定义，取值形态覆盖：空集合 / 单元素 / 全选 / 含游离值（不在选项内）。
- 定义生命周期样本：一个待改名的选项、一个待删除的选项、一个待改类型的定义、一个待删除的定义。
- 校验样本：空选项、重复选项（应被前端拦截）。
