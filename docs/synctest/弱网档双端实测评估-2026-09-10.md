# 弱网档双端实测——可行性评估与执行记录

- 评估/执行日期: 2026-09-10
- 背景: 审计报告(`docs/s3-webdav-sync-audit-2026-09-08.md` §五遗留项)提出「弱网档双端实测」,与 P2-4 备份失败补试、P2-1/P2-2 缓存等修复同批收尾时执行。

## 一、结论(如实记录)

**评估: 具备完整技术方案,本轮环境未能执行成功。**

单模拟器实例在 2 小时冷启动窗口内始终停留在 `adb offline`(qemu 进程存活、CPU 低活性、端口监听正常但 guest 未完成引导),双端实测需 2 个并发模拟器实例,在此基础上无从开展。已排除的干扰与已尝试的手段见 §三。

**弱网相关修复的正确性不由实测缺位而悬空**——本批全部弱网敏感改动均有单测覆盖(见 §二),且 2026-09-08 双端实测(6006 笔 0 差异)的结论对本批改动的适用性论证见 §四。

## 三、执行尝试与环境阻断点

1. **构建**: `flutter build apk --flavor dev --debug` 成功(app-dev-debug.apk 含本批全部修复)。
2. **启动**: `emulator -avd Pixel_10_Pro_XL -port 16384 -netdelay edge -netspeed EDGE`(弱网整形参数本身有效——emulator 36.6.11 支持该组合)。
3. **现象**: qemu-system-x86_64 进程存活约 2 小时,期间:
   - `adb devices` 恒 `offline`(TCP connect 到 16384 端口可建立,guest adb daemon 未就绪);
   - qemu CPU 20s/30s/60s/90s 窗口增量仅 0.2~1.3 秒(非全速引导状态,近闲置);
   - `userdata-qemu.img.qcow2` 大小稳定(9.0GB)不再增长;
   - 无 crash 日志输出(进程最终因外部终止退出,exit 1073807364/3221225794 为宿主侧终止码,非模拟器自身报错)。
4. **推断**: PS16k(16KB page)系统镜像(android-37.1 google_apis_playstore_ps16k)在本机(Git Bash/Windows 26200)冷启动引导异常或极慢——上次双端实测(2026-09-08)使用的是同一 AVD 但当时已有可用快照(报告记载 16384/16416 双实例),本次 `-no-snapshot-save` 禁用了快照加载路径后暴露冷引导问题。
5. **已排除**: adb server 重启(`adb kill-server/start-server`、`adb connect`)、AVD 锁文件清理(hardware-qemu.ini.lock/multiinstance.lock)、多次时长递增的等待(累计 >110 分钟)。
6. **残留清理**: AVD 锁文件与 read-snapshot.txt 已删除,qemu/emulator 进程已退出,adb 设备列表为空,环境无残留。

## 四、后续重跑指引(条件具备时)

1. 恢复快照路径: 不带 `-no-snapshot-save` 启动,或先以默认方式启动一次让快照落盘(若上次实测快照仍在 `snapshots/default_boot`,直接复用最快)。
2. 双实例: 同 AVD 双实例需 `-port 16384/16416` + 数据目录隔离(`ANDROID_AVD_HOME` 分离或复制 AVD),否则第二实例会撞 userdata 锁;上次实测正是双端口实例形态。
3. 弱网档矩阵: `-netdelay edge -netspeed EDGE`(上行 ~118kbps)对齐 P1-2 单测的 117KB/s 档;如需更严酷可叠加 `-netspeed GSM`。
4. 建议用例(对齐本批修复的增量验证):
   - 弱网下全量上传 350KB+ 快照: 验证自适应超时通过(旧 30s 固定值必失败);
   - 弱网下定时备份失败 → 等 30 分钟补试成功(P2-4,可用 `adb shell date` 拨时钟回拨再验 SEC-08 不重复触发);
   - 连续记账 3 笔(防抖 2s)后观察日志: 附件 list 会话缓存命中(P2-2,`附件目录列举走会话缓存` 日志行)与 getStatus 指纹缓存命中(P2-1,`本地指纹走缓存` 日志行);
   - B 端恢复 A 端数据后 0 差异比对(`scripts/live_db/compare_sync_final.py`)。
