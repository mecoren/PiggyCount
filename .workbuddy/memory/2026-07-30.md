# 2026-07-30

## 处理 BUG-1 残余阻塞点（disable 后云端密文不可恢复）

### 背景
- 此前 15:27 审查发现 65 项问题（致命 3 / 高危 13 / 中等 27 / 低 22），P0 的 7 项同步/加密修复经核验均已落地。
- 唯一遗留阻塞点：原 `_isUnreadableCiphertext` 仅以 `isEnabled` 判断，会把「disable 后密钥仍保留」的场景误判为不可读，导致关闭加密后无法从云端恢复存量密文（BUG-1 残余）。

### 关键运行时事实
- `TransactionsSyncManager._initialize()`（lib/cloud/transactions_sync_manager.dart:233-242）仅在 `encryptionService.isEnabled` 为真时用 `EncryptedCloudProvider` 装饰 `_provider`。
- 因此 disable 后 `_provider` 为未装饰原始 storage，`storage.download` 返回**原始密文**（非明文）。修复不能只改一处 guard，必须在未装饰下载后手动按密钥解密。

### 改动
- 用 `_decryptIfNeeded(String raw) → String?` 取代 `_isUnreadableCiphertext`：非密文原样返回；密文且 `hasActiveKey` 为真则 `decrypt`；无密钥 / 解密失败返回 null（由调用方跳过，避免 jsonDecode 崩溃）。
- 应用至 3 处调用点：`downloadAndRestoreToCurrentLedger`(416)、`downloadAndPreview`(522)、`parseRemoteLedger`(1072)。
- 测试新增 `BUG-1 残余` 组 2 例：`_DisabledButKeyedEncryptionService`（isEnabled=false, hasActiveKey=true → inserted=1）、`_DisabledNoKeyEncryptionService`（hasActiveKey=false → 返回 0,0 不崩溃）；并补 2 个 fake EncryptionService。移除一处未使用变量。

### 验证
- `flutter test test/cloud/transactions_sync_manager_test.dart`：8 项全过（含新 BUG-1 用例）。
- `flutter analyze` 生产文件无告警；测试文件剩余 3 条告警均为既有（dart:async 多余 import、SyncStatus unused_shown_name、storage 缺 @override），非本次引入。
