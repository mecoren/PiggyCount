## UI 优化评审（材质/可读性/间距）
- 产出文档：`docs/design/UI_OPTIMIZATION_REVIEW.md`（结论 + P0/P1/P2 组件清单 + 附录 A/B）。
- 关键修正（经代码核验，推翻前期口头误判）：`PrimaryHeader` 实际**未被任何页面调用**（仅定义处），处于孤立状态；全 app 头部均为 `GlassHeader/GlassTitleBar/GlassHomeBar`（50+ 页）且**不渲染 HeaderSkin** → 皮肤个性化在当前全部头部均不可见。`pageHorizontalMargin` 实为 12（非 16）。
- 用户决策：统一采用「95% 实色（同底部导航栏 `tabBarBackground` 白/深灰 α0.95）+ 头部直渲皮肤」视觉语言；玻璃不做全量系统；Mica 不采用。
- 实施方向：新增统一 `PiggyHeader`（95% 中性实色 + 直渲 HeaderSkin）替换 50+ 处 Glass* 调用；分段控件 `wait_sliding_segmented_control.dart:158` 的 surface α0.55 对齐 95% 实色；导航栏保持 95% 实色（撤回「导航栏改真玻璃」旧建议）。
- 可读性护栏：95% 中性基底 + onSurface 文字可达 AAA；若皮肤全不透明叠于其上需降皮肤 α≤0.9 或升基底至 0.97。
