# 报表增强：任意区间 + 环比/同比 + 标签维度（F2）— 需求文档

## 一、背景

现状（评估时核实）：`analytics_page.dart` 只有"上期总额"一个对比槽（周=上周、月=去年同月，
即**有同比无环比**）；时间粒度是快捷选月 wheel，**无任意起止**；标签维度未进统计页
（只有 `tag_detail_page` 的单标签 `getTagStats`）。

对标：Actual 的报表支持自定义区间与 live/static 两种口径；钱迹/网易有钱类 App 的报表页普遍
带"环比 + 同比"双列。YoY/MoM 一键对比在记账类里没人明写 → 属差异化机会。

## 二、需求范围

### R1 任意日期区间

- 用户能选任意起止日（不是"某个周/月/年"），区间内所有块随之变化。
- 右端**含末日**（用户选 9/1~9/10 就是 10 号算进去），取数统一半开区间 `[start, end)`。
- 区间超出屏幕可画的日数上限时，趋势图自动降粒度到**自然月**，不得画上千根柱。
- 支持"整窗按自身长度前后平移"（沿用洞察页左右滑手势）。

### R2 环比 + 同比双列

- 支出 / 收入 / 结余三行 × 本期 / 环比上期 / 同比去年同期三列。
- 环比 = 紧邻本期之前、**等长**的窗口；同比 = 整窗回退一年。
- 每格给变化率 **和** 对比窗绝对额（只给百分比会在基数很小时骗人）。
- 上期为 0 → 无基准，显示「—」而不是 +∞%。
- 涨跌配色按**行语义**走（支出涨=坏、收入涨=好），颜色取用户的红绿方案。

### R3 标签维度

- 区间内按标签拆分金额与笔数，与分类维度并列。
- 共享账本（Editor 侧挂在 `transaction_tag_overrides` 的标签）必须与主表标签合进同一张报表，
  否则协作者看到的构成少一半。

### R4 口径与既有页一致（硬要求）

- `COALESCE(native_amount, amount)`、`exclude_from_stats = 0`、半开区间、本地日界。
- 分类排行榜与洞察页**必须是同一份实现**（两份实现必然算出两个数）。
- v44 回收站里的交易天然不进本报表。

## 三、验收标准

1. `totalsByTag` 与单标签 `getTagStats` 逐值相等（金额 + 笔数）。
2. 口径四合一有测试：排除不计入统计 / 半开区间首秒末秒 / 按类型过滤 / `native_amount` 优先。
3. 一笔多标签分别计入，且文档写明"各行之和大于区间总额是口径而非 bug"。
4. 窗口算术有纯函数测试：`momWindow` 紧邻等长、`yoyWindow` 闰日进位、`changeRate` 四种边界、
   `rollToMonths` 并桶升序。
5. 页面级测试（不 pump 就抓不到的部分）：三个对比窗各查各的区间不串行；标签块与分类块
   不同源；维度胶囊换掉序列/分类/标签但**不动**对比表；空区间走空态而不是画一屏零柱。
6. `flutter analyze` 0 issue + 全量 `flutter test` 绿。

## 四、未纳入本轮

- 保存的报表 / 自定义报表（Actual 的 custom reports）：要新表 + 迁移 + 管理 UI，
  而现在连"用户存第二个区间"的证据都没有。
- 现金流 / 净资产曲线 / 交叉点、Excel/PDF 导出、预算结转与超支推送：F3。
- 多标签交叉筛选（"A 且 B"）：查询形状不同，先要单标签构成。
- 环比/同比列开关：三列一屏放得下，加开关是用 UI 复杂度换"少看一眼"。
