# MinePage 头部全宽主题色改造 —— 需求

> 本文件原缺失（2026-09-18 文档治理时依据 `design.md` 回填）。
> 实现细节与技术取舍见 `design.md`；本文件只定义「做什么」与验收标准。

## 1. 背景

改造前「我的」页顶部为独立 `GlassTitleBar` + 带圆角与水平边距的
`ProfileCard`，与设置列表形成「标题栏 / 卡片」两段式。参考产品（蜜蜂记账）
的顶部是一整块主题色区域，头像与统计直接置于其上，观感更聚焦。

## 2. 目标

让「我的」页顶部成为**一块占满宽度的主题色头部**，向下与设置列表自然衔接。

## 3. 需求条目

| # | 需求 | 说明 |
|---|---|---|
| R1 | 移除独立的 `GlassTitleBar` | 头部本身即标题栏，不再有第二层标题 |
| R2 | `ProfileCard` 占满宽度 | 去掉水平 margin 与圆角，背景为主题色 `colorScheme.primary` |
| R3 | 头部文案与图标高对比 | 昵称、统计数字等改用白色/高对比色，保证在主题色上可读 |
| R4 | 统计恢复为三列 | 记账天数 / 总笔数 / 账本结余 |
| R5 | 头部皮肤保留 | 用户已选 `headerSkinProvider` 皮肤时，作为装饰层叠加在主题色之上，功能不丢失 |
| R6 | 列表与头部衔接 | 设置列表从头部底部开始滚动，顶部 padding 为 0，靠卡片自身圆角过渡 |
| R7 | 状态栏图标适配 | 移除 AppBar 后需显式设置状态栏样式，保证在主题色头部上图标为浅色 |
| R8 | 刘海屏安全区 | 头部内容通过 `MediaQuery.padding.top` 避开状态栏 |

## 4. 验收标准

- [ ] `flutter analyze` 无新增问题。
- [ ] 亮色模式下：进入「我的」页，顶部为整块主题色，无独立标题栏、无圆角/边距留白。
- [ ] 滚动设置列表时头部固定不动，卡片从头部下沿开始。
- [ ] 状态栏时间/电量等图标在主题色头部上清晰可辨（浅色图标）。
- [ ] 切换到暗色模式后，头部文字与图标仍满足可读对比度。
- [ ] 已选择头部皮肤的用户，皮肤装饰仍在头部正确呈现，未被主题色覆盖丢失。
- [ ] 刘海屏/挖孔屏设备上，头部内容不被状态栏遮挡。

## 5. 不做（范围外）

- 设置子页保留原 `GlassTitleBar`，本次不统一。
- 不改 `SettingsCard` / `SettingsNavItem` / `SettingsSectionLabel`
  以及共享组件 `AppListTile` / `SectionCard` / `PrimaryHeader`。
