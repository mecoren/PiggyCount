# 账本管理上传功能（全部上传 + 单账本上传）需求文档

> 版本：v1.0  日期：2026-08-14
> 关联设计：`/prd/ledger_upload/design.md`

---

## 1. 背景与目标

### 1.1 背景

账本管理页（`ledgers_page_new.dart`）目前唯一的上传入口是"冲突解决对话框"——只有当
`SyncDiff.different` 时用户才被动触发上传；主动上传只能去云同步页（`cloud_sync_page.dart`），
且该页仅针对**当前账本**。用户希望：

1. 在账本管理里能把**所有本地账本一次性上传**到云端（备份/迁移场景）
2. 也能**针对某一个账本单独上传**（只想更新某一个账本的云端备份）

底层单账本上传 API `TransactionsSyncManager.uploadCurrentLedger(ledgerId)` 已存在，
缺的是批量能力与账本管理页的 UI 入口。

### 1.2 目标

- **全部上传**：本地账本区头部提供「全部上传」按钮（与云端账本区「全部恢复」对称），
  确认后串行上传所有本地账本，展示成功/失败结果
- **单账本上传**：本地账本长按菜单新增「上传到云端」项，上传指定账本
- **覆盖语义明确**：上传 = 以本地为准覆盖云端，确认弹窗需明确警示
- **范围限定**：仅快照同步类后端（WebDAV / S3 / Supabase / iCloud）显示入口；
  PiggyCount Cloud（增量自动同步）与未配置云服务时隐藏

### 1.3 非目标

- 不改动 `SyncService` 抽象接口（批量方法仅加在 `TransactionsSyncManager` 上）
- 不支持 PiggyCount Cloud 的手动上传（其增量同步模型下无需手动上传）
- 不做上传进度条（串行 toast + 完成结果弹窗，账本数量通常很少）
- 不做选择性多选上传（全部 / 单个两种粒度已覆盖需求）

## 2. 用户故事

### US-1：全部上传

**作为**快照同步（WebDAV/S3/Supabase/iCloud）用户，
**我希望**在账本管理页一键把所有本地账本上传到云端，
**以便**快速备份或迁移到新设备。

验收标准：
- 本地账本区头部显示「全部上传」按钮（cloud_upload 图标），与「全部恢复」风格一致
- 仅当同步服务为 `TransactionsSyncManager` 时显示；PiggyCount Cloud / 未配置云服务时隐藏
- 点击后弹确认框：显示账本数量，并警示"云端现有内容将被本地内容覆盖"
- 上传期间按钮禁用（防重复触发），toast 提示"上传中"
- 单个账本上传失败不中断整体，完成后弹结果框（成功 N / 失败 M）
- 完成后刷新账本列表与同步状态

### US-2：单账本上传

**作为**快照同步用户，
**我希望**长按某个本地账本直接上传它，
**以便**只更新该账本的云端备份，不影响其他账本。

验收标准：
- 长按菜单新增「上传到云端」项，位置在"预算管理"之后、破坏性操作（清空/删除）之前
- 仅当同步服务为 `TransactionsSyncManager` 时显示
- 上传期间该账本加入 `uploadingLedgerIdsProvider`（供 UI 显示上传中状态）
- 成功：toast「上传成功」+ 刷新账本列表/同步状态
- 失败：弹错误对话框展示原因（如未登录、云服务不可用）

### US-3：异常与边界

**作为**用户，
**我希望**边界场景下入口与提示清晰，
**以便**不会在无法上传的状态下误操作。

验收标准：
- 未登录 / 云服务不可用：入口可见，点击后走现有错误提示路径（uploadCurrentLedger 抛错）
- 本地无账本：本地账本分区本身不渲染，按钮自然不存在
- PiggyCount Cloud：全部上传按钮与菜单项均不显示

## 3. 功能清单

| # | 功能 | 位置 |
|---|------|------|
| F1 | `uploadAllLedgers()` 批量上传（串行，返回 success/failed） | `transactions_sync_manager.dart` |
| F2 | 本地账本区头部「全部上传」按钮 + 确认/结果弹窗 | `ledgers_page_new.dart` |
| F3 | 长按菜单「上传到云端」项 + 单账本上传流程 | `ledgers_page_new.dart` |
| F4 | l10n 新增 5 个 key（en/zh/zh_TW/ko） | `lib/l10n/*.arb` |

## 4. 验收清单

- [ ] WebDAV/S3/Supabase/iCloud 配置下：全部上传按钮与菜单项可见，功能正常
- [ ] PiggyCount Cloud 下：两个入口均不可见
- [ ] 未配置云服务：两个入口均不可见
- [ ] 全部上传：部分账本失败时结果弹窗正确显示 success/failed 计数
- [ ] 单账本上传成功后，该账本同步状态变为"已同步"（复用 uploadCurrentLedger 的缓存更新）
- [ ] `flutter gen-l10n` 通过、`flutter analyze` 无新增告警
