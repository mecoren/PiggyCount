# 需求文档：自定义字段「必填校验」

## 1. 需求理解

自定义字段定义支持设置「必填」；设置为必填的字段在手工记账（新建 + 编辑交易）时必须填写，未填则拦截保存并 Toast 提醒缺少哪些字段。必填字段的录入位以红色 `*` 标记，管理列表以「必填」徽标提示。

已确认的交互决策：
- **校验范围**：新建交易 + 编辑存量交易都拦；周期账单模板编辑、CSV 导入、云端恢复等非手工记账路径**不拦**。
- **提醒形态**：字段名旁红色 `*` + 提交时 Toast 拦截（与现有「必须选分类」同款交互，见 `amount_editor_sheet.dart` 分类必拦范式）。

## 2. 背景与用户价值

- 现状：自定义字段（v46）只支持名称/类型/选项，无必填语义。用户设了「备注」「项目」等关键字段后，记账时容易遗漏，事后统计口径不完整。
- 必填是表单类自定义字段的通用能力（对标各类记账/报销产品），补齐后自定义字段才能承担"结构化记账要素"的角色。
- 只在手工记账口拦截、批量路径放行，保证历史数据恢复/导入不被卡死——这是本需求最重要的产品边界。

## 3. 功能范围

### 3.1 定义侧（自定义字段管理页）

| 项 | 说明 |
|---|---|
| 必填开关 | `_CustomFieldEditSheet` 类型选择器下方新增「必填」开关行（标签 + 副文案「记账时必须填写该字段」） |
| 默认值 | 新建字段默认**非必填**；存量字段迁移后一律为非必填 |
| 列表徽标 | 管理列表 tile 副标题在类型标签后追加「· 必填」（仅 isRequired 时显示） |
| 跨设备 | 必填随字段定义同步（定义本身是同步实体），多端行为一致 |

### 3.2 记账侧（AmountEditorSheet）

| 项 | 说明 |
|---|---|
| 必填标记 | `CustomFieldsSection` 中 isRequired 字段的名称后缀红色 `*` |
| 提交校验 | 「完成」键提交前校验所有 isRequired 字段已填；未填则 Toast「请填写必填字段：{names}」并拦截保存 |
| 已填口径 | 与落库语义同口径（`CustomFieldValueCodec.normalize`）：金额 0 合法、空串/空列表/缺键 = 未填 |
| 校验入口 | 仅手工记账表单「完成」键路径；周期账单模板（同一录入控件显示 `*` 但不拦）、CSV 导入、云端恢复、合并「一键应用全部」均不拦 |

### 3.3 不做（明确排除）

- 不做"逐字段行内红字报错"，只做 Toast 拦截（与分类必拦一致，避免表单内联校验体系的扩散）。
- 必填开关**不进** `detectCustomFieldEditHazard` 双重危险确认（非破坏性变更）。
- 不回填历史交易：历史交易在字段改必填前已存在、未填值，下次编辑时被要求补填（用户已确认此口径）。

## 4. 数据与同步影响

- `custom_field_definitions` 新增 `is_required` 列（INTEGER NOT NULL DEFAULT 0），schema v54 → v55，零回填。
- 云端快照格式 v13 → v14：`customFields` 每项恒写 `isRequired` 键（含 false）；导入侧键存在三态（缺键 = 真·旧快照 → 保留本地；显式值 = 云端权威覆盖）；同步指纹纳入该键。版本升级触发一次性全量重传门控，旧云端快照自动收敛。

## 5. 边界条件与风险

| 编号 | 风险 | 处置 |
|---|---|---|
| R1 | 旧客户端（快照 v13）收到 v14 快照 | 解析侧对未知键宽容（缺键/多键不炸），旧端忽略 `isRequired`；新端读旧快照按缺键三态保留本地值 |
| R2 | 编辑存量交易被拦（历史数据无值） | 用户已确认接受：编辑时补填即可，避免存量口径被静默改写 |
| R3 | 转账入口复用同一表单 | 转账同样拦（同一「完成」路径）；转账无分类但自定义字段行为一致 |
| R4 | 金额类必填字段值在数字键盘暂存区 | 校验前先 `_applyCustomFieldAmountValues()` 把键盘字符串值并入 `_customValues` 再判，避免"看着填了却提示未填" |
| R5 | 多语言 4 个 arb（zh / zh_TW / en / ko） | 新增 4 键（label/hint/badge/missing），`flutter gen-l10n` 重新生成 |

## 6. 验收标准

1. 管理页新建/编辑字段可设置「必填」，列表 tile 显示「· 必填」徽标；开关保存后即时生效并参与同步。
2. 必填字段在记账表单名称后显示红色 `*`；不填点「完成」弹 Toast 且不出 onSubmit；填写后正常保存。
3. 编辑存量交易同样被拦；转账入口同样被拦。
4. 周期账单模板编辑、CSV 导入、云端恢复路径不因必填被拦。
5. 双端同步后必填标记一致；旧快照缺键不覆盖本地值，显式值覆盖。
6. `flutter analyze` 零告警，`flutter test` 全绿（含 schema/migration/sync 契约回归）。
