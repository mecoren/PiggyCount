# 需求文档：洞察模块自定义字段统计全链路（字段配置→采集→聚合→可视化→筛选导出）

> **状态：已落地**（2026-10-13 拟稿含行业对标结论，2026-10-14 阶段 1-4 完成，阶段 5 验收中）。
> 前置已落地：`prd/analytics_custom_field_card/`（③值桶汇总卡）、
> `prd/analytics_card_registry/`（②卡片注册表 + 命名数据包）、
> `prd/custom_field_required_attribute/`（必填属性）。
> 行业对标来源：Firefly III / Actual / YNAB / MoneyWiz / 钱迹 / 随手记等 9 款产品
> （对标结论见 §二）。

## 一、需求理解

在自定义字段现有「值桶笔数+金额」一刀切统计的基础上，补齐**按字段类型的差异化
统计口径**与**统计全链路**：金额型求和/均值/分布、日期型时间分布、枚举型 TopN
占比；并新增「字段分析」下钻详情页、按字段值筛选明细、聚合+明细双份 CSV 导出。
目标是让自定义字段从「记账附加信息」升级为**一等统计维度**（对标分类维度），
且结构化字段（金额/日期）的统计能力为行业空白，作为差异化竞争力。

## 二、行业对标结论（调研摘要）

**做得好的借鉴**：
1. TopN 排行 + 占比 + 「其他」截断（YNAB Spending Breakdown）；
2. 图表→分组→单笔三级下钻（YNAB Spending Trends / 随手记）；
3. 快捷区间 + 周期环比增减（钱迹 / Actual）；
4. 筛选 chips 可视化 + 报表联动（Actual）；
5. 聚合+明细双份导出 CSV（YNAB Export）；
6. 标签/字段渐进披露、归档软删除（钱迹）。

**行业空白（本项目差异化）**：9 款产品均无「结构化自定义字段（金额/日期/多选）
的分类型聚合统计」——本项目字段类型已齐（amount/text/date/singleSelect/
multiSelect），统计口径升级后即形成差异化能力。

**明确不做（过度设计）**：BI 拖拽透视/热力矩阵、公式/关联字段、脚本化规则引擎、
自定义仪表盘编辑器、字段订阅告警、多人协作统计。

## 三、功能范围

### F1 分类型统计口径（服务层，核心）

| 字段类型 | 统计输出 |
|---|---|
| amount 金额 | 求和、均值、极值（min/max）、分布桶（按数量级分段） |
| date 日期 | 按月/按周时间分布（笔数+金额序列），复用图表组件 |
| text 文本 | 值桶 TopN + 占比 + 笔数（现状保留，topN 可配） |
| singleSelect 单选 | 同文本值桶（选项自带排序，按定义 options 顺序） |
| multiSelect 多选 | 同文本值桶（现状逐选项拆桶语义保留） |

- 金额口径沿用 `nativeAmount`（与分类统计同源）；排除不计收支交易（现状口径）。
- 空值/未填行不计入分子，但「填写率」（填写笔数/总笔数）作为字段级指标输出。

### F2 字段分析下钻页（可视化）

- 入口：洞察页自定义字段汇总卡点击「进入分析」；卡片本身保持轻量（现状值桶）。
- 分析页内容：字段切换（chips/横向列表）→ 分类型统计卡（F1 口径）→ 图表
  （金额=分布柱状；日期=趋势折线；文本/枚举=值桶条形排行）→ 点击图表元素
  下钻到该值的交易明细。
- 显隐口径与洞察页一致：结余视角隐藏、无数据自隐藏、含外币折算文案一致。

### F3 按字段值筛选明细

- 明细筛选模型增加「自定义字段 = 值」条件（金额型支持区间）；筛选 chips
  展示已生效条件、可单条移除（Actual 范式）。
- 下钻即筛选：分析页点击值桶/图表元素 → 明细列表带该筛选条件打开。

### F4 统计导出（双份 CSV）

- 聚合 CSV：当前字段（或全部字段）的统计汇总表（含填写率、各口径数值）。
- 明细 CSV：当前筛选条件下的交易明细（含各字段值列）。
- 新建通用 CSV 生成服务（纯函数，供本需求与未来报表导出复用）；导出走系统
  分享通道（与现有分享基础设施一致）；UTF-8 BOM 保证中文 Excel 兼容。

### F5 字段配置侧小增强

- 自定义字段管理页：字段行展示「已填写 n 笔」计数（引导用户知道数据完备度）；
- 本批**不新增字段类型**（布尔场景可用单选覆盖）。

## 四、验收标准

1. 五类字段在分析页均有分类型统计输出，口径与 F1 表逐项一致；金额均值/
   极值/分布、日期月分布经特征测试钉死。
2. 下钻链路可达：洞察卡 → 分析页 → 值筛选明细，全程筛选条件可见可移除。
3. 聚合/明细两份 CSV 可导出可打开（中文无乱码），聚合含填写率、明细含字段列。
4. 全量 `flutter test` 绿（既有断言零改动）、`flutter analyze` 0 issue、
   l10n 四语言齐全、真机（MuMu）五类字段逐一目检。
5. 结余视角隐藏、含外币折算、空态文案与洞察页现状口径一致（F4 冻结复用）。

## 五、未纳入（明确不做）

- 新增字段类型（boolean/公式/关联/附件）；
- BI 级透视、热力矩阵、交叉报表、自定义仪表盘布局；
- 规则引擎自动打标、字段订阅告警、AI 预测；
- 用户可配置卡片显隐/排序（延续卡片注册表批次的裁定）；
- 图表截图分享海报（导出先行，海报评估后另立项）。

## 六、边界条件与潜在风险

- **R1 统计口径红线**：排除不计收支、nativeAmount 折算、多选拆桶语义是既有
  冻结口径，升级只加新口径不改旧口径（旧值桶输出保持逐值兼容）。
- **R2 性能**：4 万交易 × 多字段聚合需避免 N+1 查询（一次取行、内存聚合，
  延续 customFieldStatsRows 范式）；分析页数据自取 provider 缓存语义延续
  U8 记忆化经验。
- **R3 CSV 注入**：以 `=`/`+`/`-`/`@` 开头的单元格需前缀转义（防公式注入）。
- **R4 明细筛选与现有筛选正交**：新增条件并入现有筛选模型，不破坏既有筛选
  测试断言。
- **R5 行为冻结**：洞察页现有值桶卡片渲染逐像素不动，只加「进入分析」入口。
